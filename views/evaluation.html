Research Approach

In this project, we assess ChatGPT's efficiency and accuracy across multiple domains. Node.js and Express create a local server to manage requests and communicate with the database. MongoDB stores questions, expected answers, ChatGPT responses, and performance metrics. WebSockets (ws) provide real-time progress updates, while the ChatGPT API generates answers that are evaluated for accuracy and response time.

Dataset Overview

The evaluation dataset covers three domains, each with at least 50 questions:

  • History: Major events, influential figures, and societal changes such as the Industrial Revolution and world wars.
  • Social Science: Topics in psychology, sociology, and economics, focusing on theories and real-world applications.
  • Computer Security: Concepts in cybersecurity, including encryption, network vulnerabilities, and malware protection.
